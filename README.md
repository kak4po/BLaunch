### Install
1. Turn the Switch off and put the SD card in your PC.
2. Extract the zip and copy `atmosphere`, `Blaunch` and `switch` to the root of the SD card (merge folders).
3. Put the SD card back and turn the Switch on.

   **Please note this is** *Early access* **and there may be bugs, any issues 
   please contact me on: [Discord](https://discord.gg/q4qknMESsr) 💬**

### Highlights
- Glass home screen with a dock (pin up to 3 games), status bar and button guide
- 1 to 3 rows of games; press the right / left stick to show more / fewer
- Move games anywhere; empty slots are outlined
- Touch screen support
- Manage software with − (size, version, Archive, Delete, Delete save data)
- Games that need an update open anyway
- Modern Settings and Themes screens, glass pop-ups, and an Xbox-style user picker
- 8 themes included: Crimson, Emerald, Royal Gold, Deep Ocean, Lavender, Graphite, Bubblegum and **hacked.exe** (falling green code)
- Custom boot logo (Atmosphère and hekate)
- First-start setup page, and the BetterLaunch app for all settings
- Safety: if it fails to start 3 times in a row, it switches itself off and the console boots to Nintendo's HOME Menu
- Uninstall from the BetterLaunch app (System > Uninstall Blaunch)

Tested on firmware 22.5.0 with Atmosphère 1.12.0. See INSTALL.txt in the zip for controls and details.
